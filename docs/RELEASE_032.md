# Ready Personal Finance — release 0.3.2

Statement review now selects active receivable/payable posting accounts from the chart, as well as existing lending/borrowing accounts. Unlinked chart leaves are attached to obligation tracking atomically with approval; existing balances are not posted again. New receivable/payable accounts can be created in the review screen at zero balance, without a second bank transaction.

Outgoing money owed back uses lend (debit receivable, credit bank). Incoming reimbursement uses collect (debit bank, credit receivable). Money received to return or pass on uses borrow (debit bank, credit payable). Repayment or onward payment from held funds uses repay (debit payable, credit bank). These principal movements stay outside household income/spending. Repayment and collection cannot exceed outstanding balances. Names follow chart account renames; archived accounts cannot be selected or posted to. Parent headings remain report groups.

Selected rows post oldest date first, independent of newest-first bank export order. Within the same date, selection order is retained; statements without times cannot establish intraday order. All approved rows remain atomic and retries cannot post twice. If the funding entry is in a different approval or statement, post it first before approving its repayment.

Archive removes an upload from the active list, preserving staged rows, financial journals and duplicate links. Separate archived history supports Restore. Archived batches cannot remap or post. Archived unused uploads do not prevent a zero-balance bank account from being archived. Review starts with pending rows only; Show reviewed rows recalls completed/skipped/duplicate rows. Close review collapses the current preview. Active and archived lists each display the latest 100 uploads; row review uses pages of 50, with at most 100 selected rows per approval. Archive is reversible; permanent statement erasure is not included.

No new database migration is needed for installations already enabled through versions 004, 005 and 006. Existing config, storage, installation identity, owner and public entry point must be retained. The complete update includes prior 0.3.1 features. This package has not been uploaded to Bluehost; no real household books were edited.

Validation: 64 isolated statement tests (including CSV/XLSX/XLS/text PDF readers, on-behalf posting, existing balances, reverse approval order, overpayment, scoping, atomic rollback, principal corrections and archive duplicate detection); 15 statement API authentication/CSRF/role checks; 39 correction/account checks; 33 core financial and 18 chart checks. PHP/JS syntax and ZIP file integrity/checksums are verified. Local browser tests cover selectors, inline payable creation, four synthetic postings, archive/restore, reviewed-row filtering and phone/desktop layout. Local preview is not a hosted or physical Samsung device test.
